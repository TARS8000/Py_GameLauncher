# Py_GameLauncher
ゲームやアプリを紐づけ、起動できるようにするランチャーです。

# 開発環境
Windows11 64bit  
Spyder  
使用AI：Copilot  

# 開発経緯
高校在学中に部活動でゲームを作成し、文化祭に展示していました。  
その際、パソコン１つ１つにゲームを起動させ、１パソコン＝１ゲームの方式を取っていました。  
しかし、遊ぶ人は他のゲームがしたいときに他のパソコンに移って遊ばなければならず、ユーザビリティ的に良くないと感じました。  
高校のパソコンは全て共有のクラウド形式のドライブにアクセスできていました。ここにゲームの実データを置き、exeなどのパスをアプリケーションで一括で叩けるようなゲームランチャーを作ればユーザビリティを確保できるのではと考え開発に至りました。
