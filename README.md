# Py_GameLauncher
ゲームやアプリを紐づけ、起動できるようにするランチャーです。

# 開発環境
Windows11 64bit  
Spyder  
使用AI：Copilot  

# 開発経緯
高校在学中に私は部活動でゲームを開発し、文化祭に展示していました。  
その際、パソコン１つ１つにゲームデータを入れてゲームを起動させる、１パソコン＝１ゲームの方式を取っていました。  
しかし、遊ぶ人は他のゲームがしたいときに他のパソコンに移って遊ばなければならず、ユーザビリティ的欠陥を感じました。  
高校のパソコンは全て共有のクラウド形式のドライブにアクセスできていました。  
ここにゲームのデータを置くことはできましたが、データ保管場所は部活用フォルダに制限されおり、かつまた部活用フォルダは多数のフォルダを介さないとたどり着けない難解な位置にありました。  
そこで、exeなどのパスをアプリケーションで一括で叩けるようなゲームランチャーを作れば良いのではと考え、開発に至りました。

# 主な仕様
主な仕様は下記の通りです。
| メソッド（機能ブロック） | 役割 |
| :--- | :--- |
| `load_data` / `save_data` | JSONファイルとの間でゲーム一覧データを読み書きする。 |
| `load_images` | 登録された画像を読み込み、画面サイズに合わせて自動リサイズする。 |
| `create_widgets` | ボタン、画像、説明文などの画面パーツを配置する。 |
| `confirm_and_launch` | 選択中ゲームのショートカットを一時生成し、Windowsの機能で安全に起動する。 |
| `request_password` / `check_password` | 編集モードを開くためのパスワード認証ダイアログ処理。 |
| `open_editor` | ゲーム追加・パス変更・説明文編集ができる管理者用ウィンドウの生成。 |

Epic GamesやSteamのようなゲームランチャーを参考に、ローカル環境のみで動く拡張性のあるゲームランチャーをコンセプトに制作しました。  
管理者はゲームの起動パスさえ入力すれば自分の作ったゲームを登録でき、いつでもランチャーから起動できる状態にセットできます。  
登録したゲームはJSON形式でパスが保存されるため、起動毎に登録する必要はありません。また、JSONにはゲームタイトル・サムネイル画像・説明を登録でき、ユーザーが実際に選んで遊べるようにもなっています。  
また、ゲーム以外にもソフトウェアやサイトのショートカットなどを登録すれば、それらの起動も容易に行えます。  
  
尚、起動が確実に成功するように、起動パスを基にショートカットを作成して、それを叩く方式で起動処理が行われます。この仕様になっているのは、部活動で作成したゲームのexeファイルをcmdで直接叩くと起動できないという固有のバグに対応するためです。この仕様により、ファイルの起動の確実性を上げています。
